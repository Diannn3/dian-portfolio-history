## The idea

UPPETITE ELBI is a food-discovery system designed around the UPLB / Los Baños community. Rather than treating places as a flat list, the interface treats location, nearby context, and structured place information as first-class parts of discovery.

## What the system is exploring

- A lightweight map experience for browsing nearby food places.
- Structured place data that can be maintained and reviewed instead of buried inside one-off UI code.
- Community contribution flows for adding places and proposing corrections.
- Verification as a separate step from contribution, so community input can remain useful without becoming unstructured.

## Spatial direction

The map is not decoration. It is the primary index: roads, clusters, landmarks, and place nodes should help a visitor understand *where* something is before reading every detail about it.

## Current status

The project is still being developed. The case study intentionally avoids claiming adoption, validation, traffic, or launch outcomes that have not been verified.
