## Challenge

Indoor and campus navigation has different constraints from ordinary street maps: level changes, rooms, landmarks, entrances, and incomplete positioning data all matter.

## Approach

The experiment explores floor-plan representation, routing, landmark search, multi-level spatial UI, and selective 3D representation where depth genuinely improves orientation.

## System

The project separates route data from visual representation so the interface can evolve from a clean 2D plan into richer spatial views without requiring the whole experience to become 3D.

## Current state

**Experiment.** The interface is under active exploration and should be described as a prototype until a specific deployed version is verified.
