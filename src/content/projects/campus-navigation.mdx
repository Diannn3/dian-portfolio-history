## The idea

This body of work explores navigation at two connected scales: moving across a university campus and moving through a specific building once you arrive.

## Map to building

A useful route should preserve context as the user moves from an outdoor map to an indoor floor plan. The visual system therefore treats paths, entrances, floors, rooms, and landmarks as one spatial vocabulary.

## Interface direction

The experiments use floor-plan geometry, level switching, route traces, building silhouettes, and landmark labels. The aim is clarity first, with 3D used only when it improves spatial understanding.

## Current status

This is experimental navigation work. The portfolio intentionally avoids claiming complete campus coverage, production deployment, or validated routing accuracy.
