## 3. Problem & User Context
Local service businesses in regional hubs frequently rely solely on cluttered social media pages, suffering from rampant booking scams, lack of official rate visibility, and repetitive customer inquiries. Aescent provides structured, fast, verified one-page web architectures.

## 4. Constraints
- High Performance Baseline: 100/100 Core Web Vitals on mobile cellular networks.
- Zero Operational Overhead: Client sites must require zero database maintenance or security patching.
- Rapid Delivery Cycle: Architecture modularity enabling rapid custom turnaround.

## 5. Architecture
- **Static Site Engine**: Astro 5 delivering pre-rendered, zero-client-JS pages.
- **Design System Tokens**: Strictly defined Tailwind CSS tokens enforcing typography, 8pt spatial cadence, and accessible contrast ratios.
- **Edge Deployment**: Global edge CDN caching with automated staging previews via Vercel.

## 6. Key Decisions
1. **Pure Static Generation**: Eliminating server-side runtime dependencies to prevent downtime and eliminate vulnerability surfaces for non-technical small business owners.
2. **Built-In Trust Framing**: Integrating official verification badges, permit visibility, and direct WhatsApp/Messenger routing into hero viewports.
3. **Anti-Vibecode Engineering**: Enforcing bespoke art direction and eliminating generic AI templates.

## 7. Known Rejected Alternatives
- *WordPress / Heavy CMS*: Dynamic CMS platforms were rejected due to security vulnerability overhead and database maintenance burdens on local business clients.
- *Subscription Page Builders*: Proprietary monthly SaaS site builders were avoided to prevent client vendor lock-in.

## 8. Implementation Details
The agency framework utilizes structured Astro component blueprints (`Hero`, `TrustBar`, `RatesGrid`, `AmenitiesGrid`, `BookingFAQ`) paired with strict JSON-LD LocalBusiness schema for local SEO visibility.

## 9. Validation & Testing
- Automated Playwright responsive screenshot audits across mobile, tablet, and desktop viewports.
- Lighthouse performance testing ensuring $< 0.8\text{s}$ Largest Contentful Paint (LCP) and zero Cumulative Layout Shift (CLS).
