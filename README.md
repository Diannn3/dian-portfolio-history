# Dian Portfolio

Personal portfolio website built with Astro, React, Three.js, React Three Fiber, Spline, GSAP, Tailwind CSS, and shadcn/ui.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
4. Run tests:
   ```bash
   npm run test
   ```

## Configuration

- Update personal links in `src/components/global/Footer.astro` and `src/components/contact/ContactSection.astro`.
- Spline scene URL in `src/components/spline/DigitalArtifact.tsx`.
- Content collections in `src/content/projects/`.
